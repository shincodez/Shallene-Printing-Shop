# Shallene's Printing Shop Website

A modern, responsive business website for Shallene's Printing Shop, showcasing its printing services, document solutions, available products, pricing information, and contact details.

## Project Overview

This project aims to establish an online presence for Shallene's Printing Shop through a clean, accessible, and mobile-friendly website.

The website will help customers:
- Explore available printing and document services.
- Browse product categories.
- View confirmed service pricing.
- Check business hours.
- Contact the shop.

## Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Local Development

### Requirements

- Visual Studio Code
- A modern web browser

### Running the Website

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Use the Live Server extension if installed.
4. Click **Go Live** to preview the website in your browser.

Alternatively, open `index.html` directly in your browser.

## Development Guidelines

- Follow `CLAUDE.md` for project-specific instructions.
- Maintain the existing folder structure.
- Keep HTML, CSS, and JavaScript separate.
- Use actual business information and supplied assets.
- Do not invent prices, services, or business details.
- Test responsive behavior before committing changes.
